# 选择宿主

| 环境 | 开始办法 |
| --- | --- |
| [WorkBuddy](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market) | 在私有任务按官方入口尝试导入 Skill，或提供指令与必要文件。浏览器权限另核。 |
| [DeepSeek Harness](https://www.deepseek.com/en/harness/) | 打开私有工作目录，指定读取 SKILL.md 和交付位置，按可用搜索、浏览与文件能力执行。若只用 [DeepSeek API](https://api-docs.deepseek.com/guides/tool_calls/)，由你的宿主提供文件、网页和状态工具。 |
| [Codex](https://developers.openai.com/api/reference/cli) | 将完整目录放入私有项目的 .agents/skills/，确认宿主加载 Skill；按实际工具能力决定是否查网页。 |
| [Grok Bot](https://docs.x.ai/grok-bot/computer-and-apps) | 把目标、规则和私有资料交给 Bot；分工可选，由一位写入者合并 CRM。 |
| [Muse](https://ai.meta.com/muse) / [Dots](https://help.openai.com/en/articles/20001530-getting-started-with-your-dot) | 作为一次私有任务交付目标、资料与停点；有文件权限才读包，无文件权限时提供相关说明。未验证原生导入。 |
| 自建 harness | 网页查证、文件读写、持久状态是独立能力。先跑只研究，再按需配置邮件或委派。 |

早期私下版有云端模拟站流程和 WorkBuddy 文本模式记录，不代表本公开候选已完成原生安装、邮箱联调或跨平台验证。没有浏览能力时只能分析给定资料；没有写权限时仅交待保存内容。
