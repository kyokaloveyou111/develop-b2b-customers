# AI 客户开发 Skill｜第 1 版

**新脑子定律第二条：把你会做的事，变成 Agent 能照着做的流程。**

做 ToB 销售时，我常常一上午都在找名单、翻官网、改开发信，结果跟客户一句话都没说上。我做这个 Skill，是想把写信前最耗时间的那部分交给 AI：找公开证据，说明为什么值得联系，再把下一步记下来。

- **客户开发**：先回答「这家公司为什么值得看？」再决定要不要起草。
- **CRM 跟进**：记下谁承诺了什么、谁负责、什么时候再看。
- **漏斗复盘**：说清楚这周有什么实际变化，不把「可能成交」当成进展。

## 三家虚构机构，为什么只选两家？

假设我们卖的是「活动器材交接工具」，想找经常办活动、现场需要多人交接器材的机构。下面的对象和材料都是虚构的。

| 对象 | AI 从材料里看到什么 | 第一次怎么判断 |
| --- | --- | --- |
| A：灯屿活动中心 | 每月办展，要登记器材借出和归还 | 值得继续研究 |
| B：河谷周末市集 | 志愿者清点器材，没写谁签收 | 先查交接责任 |
| C：云栈文创园 | 常办活动，但模拟记录明确写着「不再联系」 | 不联系 |

**人工反馈：**「是不是正式员工不重要。我真正关心的是：器材还回来时，有没有人负责签收？」

B 的补充材料显示，志愿者清点后由主办方签收，差异也由主办方登记。B 变成「值得继续研究」；A 不变，C 仍然不联系。这轮只研究，没有起草或发送开发信。重点不是把名单变长，而是让 AI 知道你在看哪条证据。

这是项目介绍和演示案例，不含完整 Skill、安装包或真实客户资料。想了解完整版，可以在看到本项目的原帖联系作者，带上「卖什么、想找哪个地区的客户」即可，不必发客户名单。
