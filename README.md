# ToB 客户开发 Skill｜第 1 版

把公开项目证据，转成销售团队能接手的客户开发决策。

**[下载第 1 版 ZIP](https://github.com/kyokaloveyou111/develop-b2b-customers/raw/refs/heads/main/downloads/ai-b2b-skill-v1.zip)** · [查看 SKILL.md](SKILL.md)

适合需要按市场筛选企业客户、集成商或渠道伙伴的团队。每个候选都要说清楚：**有什么证据、为什么值得联系、还有什么不知道、下一步谁接手。**

## 五分钟上手

1. 下载解压，把整个目录放到你有权使用的私有工作区，再让 Agent 读 [SKILL.md](SKILL.md)。
2. 给一个产品、一个目标市场和要找的企业角色。先研究少量候选，停在人工校准。
3. 用 [证据卡和 CRM 模板](templates/candidate.md)接手结果。需要存邮箱草稿、查回信或真正发送时，再分别确认账号和授权。

> 我卖【产品】，想找【地区】的【企业角色】。每家给项目证据、优先级、未知项和下一步；第一轮停在人工校准，不连邮箱、不发信、不定时。

## 实操｜日本室内固装 LED

一家集成商做过室内常设项目，也已有小间距产品线。**有落地能力，不能算成正在采购。** 因此它进入优先核实队列，先判断特定安装或维护条件下是否会评估外部备选，CRM 留在「研究完成／草稿待审」。[查看脱敏案例和候选排序](examples/japan-indoor-led.md)。
