# ToB 客户开发 Skill

一套面向企业销售和业务拓展人员的 AI 工作流。从具体产品和目标市场出发，回答三个问题：哪家公司值得看，哪条项目证据能说明联系理由，第一封开发信该从哪里谈起。

## 从目标市场到客户跟进

先定产品、地区和客户类型，再核对目标企业公开的项目或产品资料。每个候选客户保留来源、查阅日期和匹配理由，同时标明还没有证据的判断。

销售选定对象后，Skill 根据已核实的项目起草开发信，由销售审阅。联系之后，CRM 记录客户原话、双方约定、负责人和下次跟进时间。漏斗依据客户的实际行动更新，区分商机进展、当前卡点和成交判断。

## 应用示例｜为冷链周转箱寻找客户

以下场景为原创虚构案例。

假设你销售可循环保温周转箱，目标是给连锁门店配送冷藏鲜食的区域运营商。「汀舟鲜配」的项目介绍提到：冷藏餐盒每天从中心仓发往门店，空箱随返程车辆回仓。

**联系理由：** 对方有明确的送货和回箱场景，箱体尺寸、装车方式和空箱堆放值得讨论。但公开资料不能说明采购由谁负责，也不能证明对方正打算换箱。第一封信可以先问清选型归属。

> 您好，看到贵司在门店配送项目中采用了空箱随车回仓的安排。我们提供可循环保温周转箱，想请教一下，门店使用的箱具是由贵司统一选型吗？如果是，我可以发一页箱体尺寸图，方便您对照现有车辆和门店的堆放空间。

如果对方回复「箱型由配送部定，请周四前把尺寸图发来」，CRM 就把原话、负责人和截止日记下来。漏斗更新为「配送部已索取选型资料」；预算、采购时间和是否进入试用，仍待确认。
