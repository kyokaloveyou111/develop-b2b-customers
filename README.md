# ToB 客户开发 Skill

面向企业销售和业务拓展。把「找公司、翻官网、改开发信、记跟进」连成一条能复查的流程。每个候选都回答：**有什么项目证据、为什么值得联系、下一步要验证什么。**

## 从目标市场到 CRM

- **筛选客户。** 从产品、地区和客户类型出发，查公开项目资料，留下来源和日期，把已知事实与待核判断分开。
- **准备外联。** 针对具体项目写开发信，不套通用模板。可先交内部草稿；有发件账号及明确授权后，才在邮箱内操作。
- **接住跟进。** 在 CRM 里记下证据、负责人和下一步。把研究完成、已发送、客户回复和商机推进分开，不用名单数量代替销售进展。

## 实操案例｜日本室内固装 LED

**任务：** 为小间距商显 LED 在日本寻找集成合作方。优先看有室内常设项目、能做设计施工的企业，而不是收集所有卖 LED 的公司。

**证据：** 一家视听集成商公开了酒店公共空间的常设项目，也展示了自己的小间距产品线。项目说明它有落地能力，产品线则提醒我们：它未必需要新的供应商。公开资料无法证明它正在采购。

**判断与交付：** 把这家公司列为优先核实的集成合作方，而不是采购商机。日文内审稿围绕一个具体问题：当安装尺寸或维护条件不适合既有方案时，对方是否会评估外部备选？CRM 记录为「研究完成、草稿待审」；未发送、未读取回信，也没有把它推进到已接洽。

本案例来自一次基于公开资料的实际研究。对外已省去企业、项目及人员名称、可反查细节和内部草稿。
